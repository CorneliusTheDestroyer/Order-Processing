# Order Processing Service

A simplified e-commerce order processing API built for the Genasys C# Developer technical
assessment (July 2025). ASP.NET Core Web API (.NET 8) with Order, Inventory, and Payment
controllers, EF Core (In-Memory provider), and inter-controller communication over HTTP.

> Work in progress — this README will be filled in with architecture notes, setup instructions,
> and design decisions as the implementation is completed.
